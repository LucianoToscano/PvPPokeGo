# Changelog

## 0.1.0-phase1

- Novo projeto fonte Android/Kotlin em vez de patches binários de DEX.
- Package de desenvolvimento `com.lucianotoscano.pvppokego`.
- Foreground Service + MediaProjection + TYPE_APPLICATION_OVERLAY.
- Overlay passivo/touch-through para a Fase 1.
- OCR ML Kit em regiões de interesse para nome e PC.
- Modelo de energia 0–100 com energia residual.
- Previsão de Fast Moves restantes para Charged Moves.
- Progresso circular de energia e estrutura triangular de ataques.
- Configurações de escala, opacidade, módulos e DEBUG.
- GitHub Actions para compilar APK Debug.
- Seletores `▼`, detecção automática de Fast Move, timer e drag permanecem nas fases seguintes após validação da base.
