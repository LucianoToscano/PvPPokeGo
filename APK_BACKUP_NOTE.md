# Sobre a origem deste backup

Como o código-fonte Kotlin real da linha 0.5.25 existe no repositório, o backup editável usa a fonte original em vez de reconstruir classes a partir de smali. Isso preserva nomes, comentários, testes, Gradle, flavors e arquitetura com fidelidade muito maior.

O último APK efetivamente compilado recuperado durante a auditoria é o 0.5.22. Ele não deve ser renomeado nem apresentado como 0.5.25.
