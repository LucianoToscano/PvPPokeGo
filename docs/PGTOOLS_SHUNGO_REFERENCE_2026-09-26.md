# Referência PGTools/Shungo para PvPPokeGo

Data: 2026-09-26

PGTools 6.0.6 e Shungo 1.7.0 foram analisados como referências adicionais.

## Componentes úteis ao PvPPokeGo
- filtros de Pokémon/IV customizados;
- engine de prioridade de alvos;
- stats/logs;
- notificações;
- modelos de configuração;
- battle engine genérico;
- dados de Rocket/Raid que possam alimentar recomendações;
- organização modular.

## Componentes que ficam fora do core PvP
- auto farm;
- teleporte/joystick;
- hunt por coordenadas;
- root/Magisk;
- injeção;
- auto raid/Rocket executor;
- transferência automática.

Essas funções pertencem ao projeto Recovery; compartilhar apenas modelos/dados próprios, nunca implementação invasiva.
