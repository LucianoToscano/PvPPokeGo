# PvPPokeGo — versionamento de APK

A partir da base aprovada 0.5.10:

- Cada APK novo distribuído recebe um número novo.
- O arquivo deve usar o formato `PvPPokeGo-X.Y.Z.apk`.
- Não reutilizar um número de versão para binários diferentes.
- Sequência atual: `PvPPokeGo-0.5.10.apk` → `PvPPokeGo-0.5.11.apk` → `PvPPokeGo-0.5.12.apk` → ...
- A base visual aprovada de ícones e posições só deve mudar quando a alteração for deliberada e registrada no changelog.
